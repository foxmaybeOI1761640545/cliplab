# 动画课堂 ClipLab

请创建一个完整可运行的中文全栈网页应用，项目名称「动画课堂 ClipLab｜主题拆解与剪辑备课工作台」。这是七年级教师用于整理国产动画片段、拆解课堂主题、安排约40分钟课堂流程的个人备课工具，不是公开内容网站。

【产品目标与核心约束】
- 面向七年级学生；默认适用年级为七年级，可编辑。
- 一节课默认40分钟；所有课堂流程必须能汇总预计用时，并提示超时或剩余时间。
- 优先使用几分钟内的短片段，不建议整集播放。片段建议时长默认1–5分钟；超过5分钟给出温和提醒，不阻止保存。
- 动画片、集数、片段、主题、课堂阶段、提问设计、讨论目标、总结陈述、播放时长、资源链接、免费播放可用性、版权/平台备注都要能记录和编辑。
- 绝对不要假设某个平台一定可以播放，也不要自动把链接标为免费或授权。资源播放状态和版权状态默认「待核实」，必须由用户手动更新；实际可用链接可随时手动更换。
- 不做视频下载、绕过付费/登录/DRM或版权限制的功能。只保存用户填写的链接和核实记录。

【整体体验与视觉】
- 全中文界面，桌面端优先，同时适配平板和手机。
- 专业、温和、有课堂工作台气质；浅色背景、清晰卡片、低饱和蓝绿/暖橙作为少量强调色，留白充分，避免过度花哨。
- 左侧导航栏：备课总览、动画与集数、片段库、主题对照、课堂流程、资源核实、备课行动。
- 顶部有全局搜索、快速新增按钮、当前工作区标题。
- 表格与卡片视图切换；空状态明确提示如何新增第一条记录。不要用伪装成真实内容的假数据。可以提供一个「示例数据」开关/导入模板，但默认数据库为空；若提供示例，必须显眼标注为演示数据，不可冒充真实可用片段或资源。

【信息架构与数据关系】
请建立持久化数据模型（优先使用 Lovable Cloud/Supabase 数据库；如需要启用数据库，按平台流程处理），支持刷新后数据仍在，并实现完整新增、查看、编辑、删除 CRUD：
1. 动画作品 Animation：名称、别名、国产/制作信息（可选）、简介、主题标签、备注。
2. 集数 Episode：关联动画作品、季/集编号、集数标题、整集时长、剧情梗概、原始资源链接、备注。
3. 片段 Clip：关联动画与集数；片段名称；课堂阶段（引出问题、提出冲突、推进解决、展示结果、课堂总结）；开始时间与结束时间（支持 hh:mm:ss 或 mm:ss）；自动计算片段时长；适合课堂播放分钟数；重点画面/剪辑提示；主题（可多选：友情、自制力、情绪管理、合作，也允许自定义）；适用年级；预计课堂用时；教师提问；讨论目标；总结陈述；教学备注；资源关联；状态（构思中、待剪辑、待核实、可用、暂不使用）。
4. 资源 Resource：关联动画/集数/片段；平台名称；实际播放链接；播放可用性（待核实、免费播放、免费播放但含广告、需登录、需付费、地区受限、链接失效、其他）；核实日期；核实人/设备（可选）；播放备注；版权/课堂使用状态（待核实、已确认可用于课堂、需进一步确认、不建议使用）；版权/平台备注。状态须由用户手动设置，默认待核实。链接允许空值。
5. 课堂方案 LessonPlan：标题、主题、年级（默认七年级）、课时总长（默认40分钟）、教学目标、选用片段排序、课堂阶段、教师提问、讨论活动、总结陈述、预计用时、备注。
6. 备课行动 ActionTask：任务标题、类型、关联动画/集数/片段/课堂方案、优先级、状态（待处理/进行中/已完成/暂缓）、截止日期、备注。

数据关系需合理：一个动画多集，一集多片段，一个片段可关联多个主题；片段可关联一个或多个资源记录；课堂方案可组合多个片段并调整顺序。避免重复保存同一动画/集数名称造成孤立数据。

【页面与交互】
A. 备课总览 Dashboard
- 指标：动画作品数、已登记集数、片段总数、可用片段数、待核实资源数、待办行动数。
- 最近编辑的片段、最近核实的资源、待处理行动。
- 课堂备课快捷入口。
- 提示哪些资源状态仍待核实；不可把「待核实」算作可用。

B. 动画与集数
- 动画作品列表、搜索、编辑、删除、详情页。
- 动画详情中展示集数及各集片段数量。
- 集数列表和集数详情，可从集数直接新增片段。
- 支持记录整集时长，但强调片段优先。

C. 片段库
- 可切换表格/卡片视图。
- 按主题、动画作品、集数、课堂阶段、年级、片段状态、播放可用性筛选；支持组合筛选、搜索和清空筛选。
- 列表至少显示片段名、动画/集数、阶段、主题、时间段、播放分钟数、资源状态、版权状态。
- 新增/编辑片段表单分组清晰；开始/结束时间变化时自动计算时长；结束时间必须晚于开始时间；允许只录入时间段或暂时未知。
- 对超过5分钟的片段显示提醒。
- 详情侧栏/页面显示提问设计、讨论目标、总结陈述、重点画面和资源核实记录。

D. 主题对照
- 主题标签筛选；同一主题下比较不同动画作品/集数/片段。
- 对照维度：片段时长、课堂阶段、重点画面、教师提问、讨论目标、适用年级、播放可用性、版权状态。
- 允许用户勾选2–4个片段进行并排比较；在手机端改为纵向对照。
- 主题支持自定义，不局限于预设主题。

E. 课堂流程（重点）
- 创建/编辑课堂方案，默认七年级、40分钟。
- 以「引出问题 → 提出冲突 → 推进解决 → 展示结果 → 课堂总结」五阶段呈现流程，可拖动排序或用上下移动按钮调整。
- 每阶段可添加片段、教师提问、讨论活动、教师总结、预计用时。
- 从片段库选择片段并加入方案；自动带入该片段已有的主题、提问、讨论目标、总结陈述，但允许在本课中单独修改，不覆盖片段库原始信息。
- 显示每个阶段分钟数、全课总用时、剩余时间；超过40分钟明显提示，低于40分钟显示剩余时间。用户可修改总课时。
- 提供「课堂流程预览」模式，呈现接近教师上课时可直接使用的流程稿，可打印。
- 不强制五阶段各自都必须有片段，允许某阶段只有提问/讨论/总结。

F. 资源核实
- 资源列表按播放状态和版权状态筛选。
- 清楚区分「能打开/免费播放」与「版权或课堂使用授权」两件事。
- 手动编辑平台、链接、播放状态、版权状态、核实日期、备注。
- 一键打开实际链接（新标签页）；链接为空时显示未填写，不生成假链接。
- 支持手动更新状态并保留最近核实日期；状态变化有明确保存反馈。

G. 备课行动
- 按待处理、进行中、已完成、暂缓分组或筛选。
- 可从缺少时间码、片段待剪辑、资源待核实、版权待确认等场景创建任务。
- 提供下一步行动建议，但只根据真实数据推导，不生成虚构事实。

【辅助能力】
- 支持 CSV 导出片段、资源、动画/集数、课堂方案；提供 CSV 导入模板或简单导入功能，导入前预览和校验，避免重复数据。
- 所有列表有合理排序、空状态、加载态、错误态、成功提示。
- 删除关联数据时给出明确确认，并采用合理的级联/阻止策略，避免静默丢失。
- 提供演示数据导入入口（可选），所有演示数据必须有明显 DEMO 标记，且资源状态/版权状态仍为待核实，不得伪称实际播放可用。

【质量要求】
- 不只搭建静态 UI，主要按钮、表单、筛选、搜索、排序、编辑、删除、片段对照、课堂流程汇总、资源状态更新都必须真实工作。
- 建立适当的数据校验、空值处理、响应式布局和基础无障碍支持。
- 不要引入不必要的复杂外部 API；不自动抓取视频资源。
- 完成后检查主要页面导航、CRUD、筛选、片段时长计算、40分钟课堂用时计算、资源状态编辑和移动端布局。
- 请先把可运行的第一版完整搭建出来，而不是只回复设计方案。
